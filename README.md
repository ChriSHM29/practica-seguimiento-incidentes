# Sistema de Seguimiento de Incidentes - Práctica

Este repositorio implementa el flujo de trabajo de gestión y resolución de incidentes utilizando **GitHub Issues**, **Labels de Prioridad** y **Pull Requests**.

## Módulos del Sistema
- **Autenticación:** Inicio de sesión y control de acceso.
- **Clientes:** Gestión y registro de clientes.
- **Reportes:** Generación y exportación de reportes mensuales en PDF.
- **Navegación:** Menú principal y administración de usuarios.
